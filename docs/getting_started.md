# Getting Started

[README](../README.md) · [Installation](installation.md) · [Full walkthrough](full_walkthrough.md)

Run the example commands from the ED_MRI repository root.

This example demonstrates the complete EDMRI workflow using simulated SANDI data, from generating an oversampled dataset to optimising the acquisition protocol, applying the trained task network, and visualising the results.

### 1. Generate oversampled data

First, generate a simulated SANDI dataset using the default superdesign. The data will be saved in `examples/data/sandi/`.

```bash
python examples/generate_simulation_data.py
```

### 2. Optimise the acquisition protocol

Use TADRED to select an optimised subset of acquisitions from the superdesign and train a corresponding task network.

```bash
edmri-optimise --example
```

The input data, target data and superdesign are specified in the default configuration file, `edmri/conf/optimise_default.yaml`.

### 3. Simulate data using the optimised protocol

Generate a new simulated dataset using the optimised acquisition protocol.

```bash
python -m examples.generate_simulation_data \
    --protocol results/optimisation/examples/tadred_results/optimised_protocol.txt
```

### 4. Apply the trained task network

Apply the trained task network to the new simulated data to estimate the SANDI model parameters.

```bash
edmri-apply --example
```

The trained task network and input data are specified in the default configuration file, `edmri/conf/apply_default.yaml`.

### 5. Visualise the results

Generate plots showing the optimised acquisition protocol, simulated signals and parameter estimation results.

```bash
python examples/plotting.py
```

### Output files

The example generates files in three main directories.

#### Simulated data: `examples/data/sandi/`

| File | Description |
|---|---|
| `superdesign_protocol.txt` | Oversampled acquisition protocol, with one row per acquisition and one column per acquisition parameter. |
| `superdesign_signals.npy` | Simulated MRI signals for the oversampled protocol, with dimensions `[N, T]`. |
| `superdesign_targets.npy` | Ground-truth SANDI model parameters, with dimensions `[N, P]`. |
| `tadred_signals.npy` | New simulated MRI signals generated using the optimised protocol, with dimensions `[N, C]`. |
| `tadred_targets.npy` | Corresponding ground-truth SANDI model parameters for evaluating the trained network, with dimensions `[N, P]`. |

Here, `N` is the number of simulated samples, `T` is the number of acquisitions in the superdesign, `C` is the number of acquisitions in the optimised protocol, and `P = 5` is the number of SANDI model parameters.

#### Optimisation results: `results/optimisation/examples/tadred_results/`

| File | Description |
|---|---|
| `optimised_protocol.txt` | Optimised acquisition protocol containing the subset of acquisitions selected by TADRED. |
| `trained_task_network.pt` | Trained neural network for estimating SANDI model parameters from measurements acquired using the optimised protocol. |

#### Application results: `results/application_results/`

This directory contains the predictions generated by `edmri-apply`, i.e. the SANDI parameter estimates produced by applying the trained task network to the new simulated data.

These predictions can be compared with `tadred_targets.npy` to evaluate parameter estimation accuracy.

The plotting script uses the simulated data, optimisation results and application results to generate figures illustrating the complete workflow.

**Note:** The `--example` flag saves results to a fixed directory rather than a configuration-specific hash directory, making the example easier to run and reproduce. For regular experiments, omit `--example` to keep results from different configurations separate.
